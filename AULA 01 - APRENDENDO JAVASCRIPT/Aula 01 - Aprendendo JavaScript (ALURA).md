**Aula 01 - Aprendendo JavaScript (ALURA)**

**comandos**:

- *Alert*: emite a mensagem na página

- *Let*: cria variável e atribui seu valor

- *Prompt*: recebe a entrada do usuário

- *If/else*: condição e caso contrário

- *Console.log*: retorna a sentença no console

- Template strings: Usa \`Texto fixo com \${variável qualquer}\`, dentro de \`\`

**Símbolos de sintaxe**:

- { }: vai executar se a condição anterior se cumprir

- //: insere comentários

**operadores ternários:** criam condições na declaração das variáveis

> let palavraTentativa = tentativas \> 1? 'tentativas' : 'tentativa';
>
> **função nativa - número inteiro aleatório**
>
> let numeroSecreto = parseInt(Math.random()\*10 +1)
